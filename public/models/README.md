# Local Pose Landmarker model

The official MediaPipe Pose Landmarker Lite model is included here as
`pose_landmarker_lite.task`. If the file is missing, download the official model and save
it here with that exact name:

https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task

The model is not bundled or fetched by the app. Keep this file local to the project;
the browser loads it from the same origin as the app.
